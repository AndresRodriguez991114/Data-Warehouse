01 / CONTEXTO

El proyecto

Planteamiento del problema

Para gestionar el uso de energía solar se necesita observar cuándo se genera y consume energía. El proyecto aborda esta necesidad mediante la Casa 1, una maqueta de vivienda inteligente ubicada en Cajicá, que permite medir el comportamiento de un panel, una batería y una carga representativa.

Justificación

El prototipo ofrece al equipo una forma de estudiar la relación entre generación y consumo y explorar decisiones de gestión energética. Sus resultados son experimentales: no demuestran por sí solos el abastecimiento de viviendas reales ni de todo el municipio.

OBJETIVO GENERAL

Implementar una solución de almacenamiento y preparación de datos para el módulo de ciudad inteligente mediante un modelo relacional, la simulación de mediciones, un modelo multidimensional y un proceso ETL en SSIS.

Objetivos específicos

  1. Diseñar un modelo relacional para dispositivos, ubicaciones, mediciones y eventos.
  2. Simular mediciones con un comportamiento coherente con la maqueta.
  3. Diseñar un esquema multidimensional y un ETL con validaciones.
  4. Verificar la consistencia de los datos y analizar la eficiencia energética.
02 / PROCESO

De la pregunta a la decisión

01Comprensión del negocio

Monitorear generación y consumo en la maqueta física Casa 1.

02Comprensión de los datos

Combinar telemetría del ESP32-S3 con mediciones simuladas.

03Preparación

Transformar los registros y controlar su calidad.

04Modelado

Organizar las mediciones en un modelo dimensional.

05Evaluación

Conciliar los conteos y comprobar la repetición de la carga.

06Despliegue

Consultar agregados de Base de datosy apoyar decisiones con gráficas actualizadas.

El alcance temporal y los conteos mostrados en el dashboard se leen de la base de Base de datosal cargar la página. La maqueta física corresponde a un único ESP32-S3; el número de dispositivos y ubicaciones de la base describe los registros disponibles, no la cantidad de prototipos físicos.

Desarrollo de la solución

La maqueta utiliza un ESP32-S3 para medir voltaje y corriente del panel solar y de la batería cada dos segundos. En las pruebas se observaron voltajes de panel entre 1,68 y 2,26 V, y de batería entre 3,72 y 3,85 V. La batería es de litio; una tira LED representa la carga.

El flujo del proyecto es ESP32 → MQTT → Node-RED → SQL Server → limpieza → SSIS → Data Warehouse. Esta página consulta únicamente los agregados publicados por Supabase; no conecta el navegador a SQL Server ni expone registros individuales. El servicio de alertas por correo fue reactivado y la incidencia de permisos está resuelta.

07 / CIERRE

Conclusiones y fuentes

Conclusiones técnicas

El sitio consulta una función de Base de datosque entrega una caché de estadísticas y agregados; no consulta SQL Server ni descarga filas individuales al navegador. El refresco automático requiere que se ejecute el script de Cron de Base de datosindicado en la guía de despliegue.

Las comparaciones y sugerencias se recalculan a partir de los datos agregados actuales. Son descriptivas y deben revisarse junto con la cobertura, el período y el número de mediciones de cada grupo; no demuestran causalidad ni representan por sí solas el desempeño de una vivienda real.

Fuente de datos

Base de Base de datosdel proyecto, mediante las funciones públicas de solo lectura y sus cachés agregadas. No se publican credenciales secretas, direcciones ni registros individuales.
