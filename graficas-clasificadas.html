Tipos de gráficas

Gráficas básicas y de comparación

Comparan valores entre diferentes categorías o grupos para identificar diferencias y tendencias. Son útiles para determinar cuáles son las características más frecuentes o cómo varían los promedios según diferentes factores.

Gráficas de distribución y frecuencia

Muestran la distribución de datos en intervalos o rangos para identificar patrones de frecuencia. Permiten ver cómo se concentran las mediciones en diferentes rangos de valores.

Gráficas de relación y composición

Muestran tendencias, evolución temporal y combinaciones de variables para identificar relaciones. Son especialmente útiles para análisis de series temporales y comportamientos complejos.

Gráficas especializadas

Gráficas especializadas para análisis técnicos específicos del sistema energético. Estas gráficas permiten hacer análisis multidimensionales y combinaciones de variables particulares.
